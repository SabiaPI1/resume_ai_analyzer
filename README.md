Сервис для автоматизированного аудита резюме кандидатов. Проект направлен на оптимизацию HR-процессов: он помогает рекрутерам быстрее фильтровать поток откликов, а соискателям — находить и исправлять критические ошибки в своих CV до отправки работодателю.

## О проекте (Бизнес-кейс от VK Education)

Проект разработан в рамках продуктовой задачи (бизнес-кейса), предоставленной **VK Education**. 

В условиях высокой конкуренции на рынке труда HR-специалисты тратят часы на первичный скрининг. Часто кандидаты с хорошим техническим бэкграундом получают отказ из-за плохо структурированного резюме, орфографических ошибок или отсутствия ключевой информации. 

Данное приложение представляет собой интеллектуальный пайплайн оценки, призванный оптимизировать систему отбора кандидатов. В основе аналитического ядра лежит использование LLM-моделей (GigaChat), что позволяет системе не просто искать совпадения по ключевым словам, а проводить глубокий контекстный анализ опыта кандидата и выдавать персонализированные, осмысленные рекомендации по улучшению профиля (выступая в роли виртуального IT-рекрутера VK).

## Ключевой функционал

1. **Smart-Парсинг (PDF to Text):** Извлечение сырого текста из стандартных резюме (включая форматы hh.ru, Хабр Карьера и кастомные PDF).
2. **Извлечение сущностей (NER & Regex):** 
   * Автоматический поиск контактных данных (Email, Телефон) и профессиональных ссылок (GitHub, LinkedIn, GitLab).
   * Распознавание ФИО кандидата и упомянутых в тексте технологий/компаний с помощью SpaCy.
3. **Грамматический аудит:** Интеграция с API Яндекс.Спеллер для выявления опечаток и лексических ошибок с предоставлением контекста.
4. **Динамический AI-Анализ соответствия (LLM):**
   * Система адаптируется под любую введенную HR-специалистом должность (например, *Junior Python Developer* или *Middle QA Automation*).
   * Оценка релевантности резюме желаемой должности (скоринг по 10-балльной шкале).
   * Анализ Hard-скиллов: выявление недостающих технологий (Skill Gap Analysis).
   * Выявление структурных ошибок резюме (лишняя «вода», недостаток конкретики, нерелевантный опыт).
   * Генерация Actionable-рекомендаций (3 четких шага для улучшения CV).

## Стек технологий
* **UI Framework:** Streamlit
* **PDF Processing:** PyPDF2
* **NLP & Regex:** SpaCy (ru_core_news_sm), re
* **External APIs:** Yandex.Speller API (проверка орфографии), GigaChat API (LLM-анализ)
* **Environment Management:** python-dotenv

## Установка и запуск локально

1. **Клонирование репозитория**    
```bash
git clone https://github.com/SabiaPI1/resume_ai_analyzer.git
cd resume_ai_analyzer
```

2. **Создание виртуального окружения и установка зависимостей**    
```bash
python -m venv venv

# Активация окружения (Windows):
venv\Scripts\activate
# Активация окружения (macOS/Linux):
# source venv/bin/activate

pip install -r requirements.txt
```

3. **Загрузка языковой модели для SpaCy**
Это обязательный шаг для корректной работы Named Entity Recognition (NER) для русского языка:

```bash
python -m spacy download ru_core_news_sm
```

4. **Настройка переменных окружения** 
Создайте файл `.env` в корневой директории проекта и добавьте туда ваш токен GigaChat:   
```env
GIGACHAT_TOKEN="ваш_токен_авторизации_base64"
```

5. **Запуск приложения**    
```bash
streamlit run app.py
```

После запуска приложение будет доступно в браузере по адресу: http://localhost:8501.
